Repository: https://github.com/BirthrightPublication/forge
Branch: `development/v0.8-speech-studio`.
Production baseline: `v0.7.0` / `bab3876878b20da5c2906b85177876844d3279f1`.
The separate PR #7 startup repair was carried onto this branch with its original
commit message and tests; PR #7 and published history were not overwritten.

## Implemented source

- Unified speech editor and voice library: projects/chapters, autosave and revision
  conflicts, caret/selection markers, undo/redo, find/replace, named speakers,
  pronunciation previews, pacing and expression presets, provider-metadata filters,
  favorites, pins and voice profiles. All state uses additive local tables.
- Kokoro adapter retains original Onyx (`am_onyx`) and enumerates installed voice
  artifacts. Compatible voice tensors are blended using normalized weights.
  Ming uses exclusive official task modes, permissions for reference voices and
  revision-verified local runtime source. Neither engine is loaded in the web service.
- Separate model/runtime installation queue jobs require explicit approval,
  isolate dependencies, verify immutable publisher artifacts, preserve existing
  environments and quarantine removed models for recovery.
- Audio Effects renders 31 ordered DSP effects using FFmpeg, including Rubber Band
  independent pitch/tempo when available, real gain/EQ/dynamics/reverb/modulation,
  selection processing, bypass, measured waveforms and original/processed playback.
- Audiobook imports EPUB/PDF/TXT/Markdown/HTML/SRT/VTT without network extraction
  or script execution. Content-addressed verified segment caches survive retries;
  exact pauses, chapter assembly, cache-only exports and WAV/FLAC/MP3/OPUS/M4B
  output use actual media processing. Saved selection effects reject changed text.
- Bark's four variants use an independent recognition runtime, bounded local audio
  chunks and truthful TXT/JSON output. Whisper, its timestamps, translation and
  optional speaker labels remain available. No speculative alignment is emitted.
- TTS and effects reuse the Universal Queue and existing linear Black Scripting.
  Existing updates, downloads, Channel Watch and privacy tools are retained.

## Evidence and its scope

All local browser regression suites passed: **437 checks** (127 Studio, 26 Black Scripting,
83 generators, 88 Media Privacy, 26 V0.6 updates, 40 V0.7 and 47 V0.8).
The local bundled-Playwright executable was absent, so these runs used the installed
`/usr/bin/chromium`; CI installs and uses its own Chromium.

- Complete local Python suite: **908 passed, 3 Windows-only skipped** at the initial
  candidate checkpoint, with one existing Starlette deprecation warning.
- An additional changed-selection worker regression and its surrounding API/book
  suite passed (**51 tests**). Final commit counts are recorded by CI rather than
  assumed from this earlier checkpoint.
- The V0.8 browser harness passed **47 checks**, including Black Scripting
  chooser and configuration coverage. It drives the actual authenticated API and a real disposable
  worker. Actual FFmpeg gain, bypass, preview, original-file preservation and A/B
  playback passed; it does not install or impersonate a neural speech model.
- DSP tests use generated tones/impulses and probe real codec output. Book tests
  use real document parsing/FFmpeg but explicitly substitute a deterministic audio
  shim for neural synthesis to test cache and assembly mechanics.
- Adapter tests verify contracts, weighted tensor arithmetic, task compatibility,
  receipts, installation isolation and known failure paths. They do not establish
  audible speech quality, pronunciation or GPU throughput.
- Upgrade and code-only rollback from the checksum-verified published V0.7 package
  passed in an isolated Linux installation. Seven original scripts and 14 protected
  fixture files were preserved; both old state and newly created speech projects,
  voice favorites, download destinations and Channel Watch records survived rollback.
- Pinned package versions were checked against PyPI metadata and binary-wheel
  availability. Complete dependency resolution and native model import/inference
  acceptance remain separate gates.
- Development CI repeats the Python and browser checks and tests the application
  payload through the unchanged supplied Windows updater. Model tests in that job
  are contract tests; they are not evidence of actual Windows model inference.

## Historical local-only release blockers and limitations

**This is not a completed or approved V0.8 release.** The official model host and
Underdog site return HTTP 403 in this environment. No actual Kokoro, Ming or Bark
checkpoint was downloaded or inferred. Audible original-Onyx generation, actual
blended voice differences, Ming expression/cloning quality, Bark-vs-Whisper reference
benchmarks, native Windows model installation and physical CUDA validation remain
pending. These failures of access are separate from application test results.

Kokoro Japanese/Chinese optional phonemizers and other eSpeak-dependent language
paths are accurately marked unavailable until installed and validated. The speech
installers currently require Python 3.10–3.12; an existing FORGE Python 3.13
installation remains usable for existing tools but cannot install these speech
stacks through the current adapter. Native Ming Tiny's reference runtime is not
validated for Windows, so Tiny/podcast mode is unavailable. Qwen is an extension
point without an advertised working runtime.

Word-level Bark alignment is unavailable; choose Whisper for timestamped output.
Independent arbitrary formant shifting, convolution impulse responses and an
exciter are not advertised as implemented. DSP styling is explicitly distinguished
from native emotional synthesis. Loudness targets are not delivery certification.

Full publisher/checkpoint, tokenizer/phonemizer and dependency redistribution
obligations remain under review. No model weights, private references or third-party
runtime binaries are bundled. See the engine/effects/Bark licensing documents.

It retains the single `app/` payload contract and excludes user data, environments,
models, projects, presets, histories and both external updater entrypoints.

remain available. Preserve the installed `B:\Forge\Update FORGE.bat`, its PowerShell
script and all backups. Do not install this candidate into production before the
remaining acceptance checks and owner approval. Existing installations can continue
