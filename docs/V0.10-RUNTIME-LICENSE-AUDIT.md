# CPU runtime license review

The reviewed scope is the normal FORGE Windows source/notices ZIP and user-approved installation of unchanged publisher wheels into a private local environment. The updater ZIP contains no dependency wheels, DLLs, environments or model weights. FORGE's application MIT license remains separate from third-party terms.

The native Windows CPU evidence verifies all 60 registered wheel identities and installed versions, an isolated `pip check`, actual OPUS/Qwen/Whisper inference, and persisted installed identities. A separate native source job verifies original FFmpeg, x264, x265, Intel OpenMP and MKL legal-source archives against their independent hashes. [The audit inventory](V0.10-RUNTIME-LICENSE-AUDIT.json) records the source commits, Actions artifacts, document hashes and observed archive indexes.

The [CUDA license appendix](V0.10-CUDA-LICENSE-DELTA.json) records full hash/size verification of its two differing wheels and separately reviewed vendor terms. Exact CPU and CUDA Torch OpenMP DLLs both match the official Intel 2025.2.0 package. This license-only review does not establish CUDA dependency closure, model inference, or physical GPU acceptance.

Primary package labels are normalized identifiers for package terms. They do not replace bundled component terms. In particular:

| Package | Additional scopes retained in the review |
| --- | --- |
| NumPy / SciPy | OpenBLAS/LAPACK attribution; GCC runtime exception; NumPy libquadmath LGPL terms |
| PyAV | BSD binding; FFmpeg and GPL-2.0-or-later x264/x265 scopes; no license grant inferred from a configure-list patch |
| SoundFile / soxr | LGPL libraries and separately supplied codec/PFFFT notices |
| llvmlite | LLVM exception and separate Microsoft runtime scope |
| CTranslate2 | MIT source; exact Intel OpenMP binary/Developer Tools terms; MKL build-family terms; cuDNN terms; oneDNN Apache terms |
| Torch / ONNX Runtime | Complete publisher bundled-notice aggregates, beyond their primary package labels |

Keep original artifact bytes, supplied notices, attribution and disclaimers. Intel OpenMP's October 2021 terms permit internal personal/business use and exclude SaaS/service-bureau access. This review covers local desktop processing. cuDNN's verified SDK terms retain the NVIDIA-system target; the CUDA adapter requires compatible NVIDIA hardware, and Tiny CPU inference does not execute cuDNN. No upstream endorsement is claimed.

Full proprietary license bodies remain outside the public repository. Their exact publisher archive URLs, document sizes/hashes, binary associations and conditions are recorded in the audit. Hash-verified legacy-encoded notice bytes can be decoded privately for review without altering or publishing the original artifact.

The CPU license review does not approve rehosting or repackaging runtime binaries, hosted services, whole-SDK redistribution, or CUDA/GPU acceptance. Those future scopes must not be inferred from primary SPDX labels. GUI/updater, physical GPU, live private YouTube acceptance and the owner's final merge/publication approval remain separate release gates.
