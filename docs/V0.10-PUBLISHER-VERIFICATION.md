# Verified publisher identities and remaining license review

The current environment successfully fetched the three registered immutable
OPUS, Qwen 0.6B Base and Whisper tiny revisions. The public
[`dubbing_publisher_inventory.json`](../forge/dubbing_publisher_inventory.json)
records selected artifact sizes, Git/LFS identities and SHA-256. Small artifacts
were downloaded and hash checked; large checkpoint identities remain publisher
metadata until the separate installer downloads and verifies them. This report
does not claim model installation, inference, native Windows or GPU acceptance.

Reproduce the publisher check without installing models:

```sh
python scripts/dubbing_publisher_inventory.py --output work/publisher-check.json --evidence-cache work/publisher-cache
```

No checked-in evidence is overwritten. Discovery of an unpinned model requires
`--discover`, produces immutable review URLs and never changes `MODEL_PINS`.
Canonical publisher transfers, conflicting or malformed identities/sizes,
duplicate file names, incomplete Qwen tokenizers and differing downloaded-card
licenses fail closed. A different approved device/runtime cannot silently reuse
an existing CPU activation; the controller requires a reviewed Repair plan.

## Model license scopes

The exact OPUS Hugging Face checkpoint card declares Apache-2.0 and links the
original `opus-2020-02-11.zip`. At the inspected immutable official upstream
revision, the English-to-Russian release README identifies that same original
checkpoint, while the upstream README and `models/LICENSE` apply CC-BY-4.0 to
pretrained models. The repository's MIT source license is a separate scope.
Preserve these declarations, full terms and attribution together. The converted
checkpoint card is not a basis for silently discarding upstream model terms.
The difference still needs explicit release/distribution review; no blanket
Apache-only weight distribution approval is recorded.

Qwen's exact checkpoint card declares Apache-2.0. The official publisher's
immutable full Apache text includes Copyright 2026 Alibaba Cloud and matches
the license member of the already pinned `qwen-tts==0.1.1` API wheel. That is
supporting notice evidence, not a standalone file in the model snapshot.

Neither OPUS nor Qwen model snapshot contains a LICENSE/NOTICE sibling. Actual
checkpoint-card declarations and supporting immutable upstream terms are
retained separately in [`V0.10-PUBLISHER-LICENSES.json`](V0.10-PUBLISHER-LICENSES.json)
and `model-notices/`, with exact URLs, revisions, sizes and hashes. No checkpoint
LICENSE path is invented. `distribution_approved` remains false pending scope,
notice and owner review. The FORGE application MIT license is unchanged; these
third-party notices apply only to their identified artifacts. No weights,
private voice references or environments are bundled in this source milestone.
