# V0.10 model, runtime and license inventory

## Verification status

This inventory describes the development controller in `forge/dubbing_models.py`
and the optional descriptors in `dubbing_visual.py`/`dubbing_separation.py`. Those
files, their dependency definitions and verified installed receipts govern
actual availability. Descriptor capability flags describe implemented adapters,
not a successful model or hardware acceptance test.

At this checkpoint `MODEL_PINS` is empty. The cloud proxy returns `CONNECT 403`
for Hugging Face access, so exact model checkpoint revisions, complete download
inventories and checkpoint-specific license evidence remain unresolved. Saving
a proposed cloud network change is not the same as applying it. No model-host
access workaround, mutable `main` fallback or invented revision is used. Newly
registered packs remain unavailable rather than displaying Ready. A source-code
commit, pinned Python dependency or successful import is not a checkpoint pin
or an inference result.

The existing FORGE MIT license remains unchanged with owner approval. It does
not relicense third-party model weights, auxiliary assets or dependencies. The
release source/package must not include downloaded weights, private references,
upstream demonstration media or user environments. Models install separately
only after artifact and distribution terms are reviewed.

runtimes are isolated and atomically activated below FORGE data. Existing app,
Whisper, Kokoro, Ming and Bark environments are not upgraded in place. Different

## Readiness, resources and remaining evidence

Publisher metadata discovery checks the immutable revision, card license,
required files, positive sizes and LFS SHA-256/Git object identity. Discovery
alone does not activate a model. A ready pack needs verified artifacts,
compatible binary dependencies, safe extraction, local-only reviewed loading
and a verified activation receipt. `inference_verified` and native/physical
hardware status remain separate receipt facts. Tensor loading uses reviewed
fixed architectures with safetensors or restricted `weights_only` loading;
untrusted model-host Python is not executed.

Controller memory budgets are planning estimates: OPUS 2,000 MiB, Qwen 0.6B
4,500 MiB, Qwen 1.7B 9,000 MiB, Chatterbox 6,000 MiB, MuseTalk 8,192 MiB and
HDemucs 6,144 MiB. They are not measured RAM/VRAM, download totals, throughput or
recommendations proven for the owner's machine. NVIDIA discovery/driver checks
do not establish CUDA architecture support. No actual RTX 5080/SM120 inference,
lip-sync speed, peak VRAM or CPU/GPU quality comparison is asserted.

Remaining model gates are applied network access, exact approved checkpoint
revisions/hashes/licenses, complete native wheel inventories, GUI install and
repair/restart tests, and actual Russian translation/reference synthesis and
optional-model inference. Before distribution, retain a full dependency/license
report for the exact activated revisions and package. Until those pass, V0.10
is a development candidate; there is no verified one-click recommended pack or
final release claim.
