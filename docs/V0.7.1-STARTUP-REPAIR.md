# V0.7.1 startup repair

Base: published `v0.7.0`, commit `bab3876878b20da5c2906b85177876844d3279f1`.
Candidate branch: `development/v0.7-startup-race-fix`. Merge and release require owner approval.

## Reproduction and correction

The V0.2 extension started asynchronous authorization while later deferred scripts
were still loading. When the local API responded before `downloads_v7.js` registered
its renderer, the default `downloads` route reached the legacy tool renderer. That
renderer read a nonexistent tool description. The generic startup catch then showed
an authorization page and directed the user to Setup, despite successful authorization.

The browser harness delays the Download Studio script by two seconds while leaving
the real local API available. Before the fix it reproduced the reported message:
`Cannot read properties of undefined (reading 'description')`.

Startup now runs once at `DOMContentLoaded`, after all deferred extensions have
registered. Separate error messages identify authorization, state connection and
interface failures. Setup reads `VERSION.txt` instead of displaying a fixed V0.3
banner. The existing running-service guard remains in place.

## Validation

- The exact delayed-script reproduction fails on V0.7.0 and passes with the repair.
- 40 V0.7 browser checks passed, including injected interface and connection errors.
- 83 generator browser checks passed, including ordinary startup, browser authorization,
  storage exclusions and navigation.
- JavaScript syntax and Git whitespace checks passed.
- The development workflow runs the complete Python suite and native Windows
  maintenance/package acceptance before review. Consult the PR checks for final results.

No installed application, user data, model, environment or external updater was
modified. Published V0.7.0 tags/assets remain unchanged. This patch does not add a
database migration or change installation paths.

## Recovery while awaiting the patch

Close Setup. After active jobs finish, use the existing `Stop FORGE.bat`, then
`Open FORGE.bat`, and reload the browser with Ctrl+F5. This may avoid the timing
condition; V0.7.1 provides the deterministic correction. Reinstalling dependencies
or deleting settings is not a repair for this interface failure.
