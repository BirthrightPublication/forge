# FORGE V0.1 historical source snapshot

This tree preserves the supplied FORGE V0.1 application source for historical reference. The application identifies itself as `0.1.0` in `forge/__init__.py`. It is not the current development baseline and is not a newly verified updater-compatible release package.

The source archive SHA-256 was `63489858aa087944b0aa7097e24b072ff6ee019267de2e92e83b6ef5e6855f1e`.

Privacy preparation omitted `original_scripts/YT Download.lnk`, because Windows shortcut files can embed machine identifiers and private paths. Its corresponding line was removed from `docs/ORIGINAL_SCRIPT_SHA256.txt`. The seven retained original batch files still match their recorded SHA-256 hashes. All remaining application code, tests, dependencies, assets, and historical documentation are unchanged. This archive note is the only added file.

The original V0.1 package had no release manifest or incremental updater. Its existing test reports describe checks performed when that historical package was produced, including the original eight-file preservation check; they are retained as historical records and do not assert that eight original files remain in this sanitized tree. No new runtime tests or target-platform acceptance checks were performed while preparing this archive.

The existing `LICENSE.txt` and its scope are unchanged. It grants the existing FORGE source license and explicitly excludes user-supplied original scripts and third-party materials from relicensing.
